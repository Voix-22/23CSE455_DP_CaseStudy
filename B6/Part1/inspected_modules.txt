============================================================
EXCLUDED FROM PRIMARY PATTERN DISCOVERY
============================================================

The following were not used as primary design-pattern evidence:

1. Migrations/
   Reason:
   Entity Framework generated migration files are database-schema
   artifacts rather than the main application collaborations being
   investigated.

2. Properties/launchSettings.json
   Reason:
   Development launch configuration; not application pattern evidence.

3. FlemanApi.http
   Reason:
   HTTP request examples; not implementation evidence.

4. Generated build/output folders, if present
   Reason:
   Compiled/generated artifacts are not source-pattern evidence.

5. Frontend source
   Reason:
   Part 1 baseline scope is the ASP.NET Core backend.

6. Java backend source
   Reason:
   The Java backend is treated as an external/legacy dependency
   when analyzing the .NET JavaMicroserviceClient integration.
   It is not part of the primary ASP.NET Core baseline.

7. Secrets / credentials in configuration
   Reason:
   Not required for pattern discovery and must not be committed
   to the submission repository.
