4. MIDDLEWARE PIPELINE / CHAIN OF RESPONSIBILITY
------------------------------------------------------------

Candidate:
Middleware Pipeline / Chain of Responsibility

LLM status:
CONFIRMED

Human status:
CONFIRMED

Files inspected:
- Middleware/ExceptionHandlingMiddleware.cs
- Middleware/RequestLoggingMiddleware.cs
- Program.cs

Exact source evidence:
ExceptionHandlingMiddleware receives RequestDelegate and forwards
processing using _next(context).

RequestLoggingMiddleware also receives the downstream delegate, performs
processing before and after the downstream component, and calls
_next(context).

Program.cs composes the middleware into the ASP.NET Core request pipeline.

Reason:
The source demonstrates the sequential request-processing behavior
associated with Chain of Responsibility. The implementation should be
described primarily as the ASP.NET Core Middleware Pipeline, with
Chain of Responsibility as the corresponding pattern interpretation.
